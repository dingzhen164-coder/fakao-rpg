# 法师成长记 · 版本更新记录

每次改 rpg/version.py 的版本号，都在最上面加一节（tests/test_device.py 会检查最新一节和版本号对得上）。
设置 → 🆕 版本与更新 → 「版本更新记录」读的就是这个文件。

版本号规则（x.y.z）：
- 第三位 z：小更新（修 bug、调界面、给已有功能加个按钮 / 选项）；
- 第二位 y：较大的更新（一个板块里加一个新功能）；
- 第一位 x：增加大板块（顶栏多一个新板块），或整体大改。

## 2.0.0 · 2026-10-09
- 🔮 整体换成「法师成长记」：以行测修仙传 3.3.0 为底本完整复制，改成法考版，固定西方玄幻风格（王立法学魔法学院、导师艾琳学姐）
  - 位阶：平民 → 魔法学徒（一至九星）→ 初级法师 → 中级法师 → 高级法师 → 大魔导师 → 法圣 → 法神·上岸者
  - 魔力（预估分）是百分制，×3 约等于客观题分数；60 分（180 分及格线）就是初级法师，跨大位阶要通过晋升试炼
  - 经验圆满后自己在营地「⚡ 按住晋升」，有蓄力动画和晋升大典；有效学习每分钟 +1 经验，前期升得快、后期慢
- 法考八科：民法、刑法、民诉、刑诉、行政法、商经知、三国法、理论法，各是一种天赋；分四批（民刑 → 两诉 → 行政商经知 → 三国理论）
  - 每科的资料默认读库里的「10-科目/<科目>」笔记文件夹（规则.md 的「板块.科目」可以改成别的文件夹或 skill），学姐据此编咒文书、讲题
- 试炼塔支持法考题型：单选、多选、不定项（题库里写「### 题型」，多选答案写 ABD，全对才算对）；每科一个题库模板
- 竞技场（模考）、封神典礼（法考）成绩按满分 300 填，程序换算成百分制
- 时间线：2026-12-01 开始，每天 180 分钟，目标日 2027-09-10（规则.md 里改）
- 学姐的出题、讲题、制卡、整理手写笔记都改成法考口径（以现行法条为准，拿不准会提示核对）
- 行测专用的板块先收起：粉笔模考分析（原宗门大比页）、时政简报（天机简报）、成语实词录；模考成绩在「编年史」里记
- 和行测修仙传可以装在同一台电脑、同一台平板上：设置存在 ~/.fakao-rpg，默认端口 8766，平板 App 包名不同；不会误用行测库（有 FB模考试卷复盘 的文件夹会被拒绝）
