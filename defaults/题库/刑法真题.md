# 刑法真题

程序按文档出现顺序抽题，编号是固定身份，请勿修改已做题的编号或重复使用。
每题用 `## 题目 编号` 开头，下面的小节标题保持一致。题目都是 A/B/C/D 四个选项。
**题型**：`### 题型` 写 单选 / 多选 / 不定项（法考卷二）。不写时：答案一个字母算单选、多个字母算多选。
多选、不定项的答案直接写字母，如 `ABD`（顺序、空格、逗号都不要紧）；必须全部选对才算对。
示例放在代码块中，不会被抽取；添加真题时复制代码块里面的内容到代码块外，并替换所有占位文本。
有来源的题在题干最前面用括号写来源，如“（2023年法考卷二）”；没有就不写。
答案、解析不知道可以写“（待补）”，答案待补的题先不出。

```markdown
## 题目 001
### 知识点
填写考点，例如 表见代理
### 题型
多选
### 题干
填写完整题干（案例题先写案情）。
### 选项
A. 填写选项
B. 填写选项
C. 填写选项
D. 填写选项
### 答案
AB
### 解析
填写依据的法条、构成要件和每个选项的对错理由。
```
