## 春季横屏制作与来源

12 处春季新图基于 8 张原生地形块合成（相邻重叠 64px），局部地形另有原生重绘块；12 座建筑各自生成并抠图后按布局缩小合成，未放大低分辨率图冒充 4K。黄昏和夜晚的地形使用低频光照参考，建筑则分别以白天单体生成时段版本并注册到白天轮廓；夜空星点由程序生成。`provenance.json` 的 `springMinimal` 保存各时段地形块、重绘、建筑素材的原生尺寸、缩放比例与 SHA256，以及最终文件摘要和 HSV 色相统计。原图和中间素材仅保留在本次工作区，不随仓库分发。

画面不含可点击热区；横屏名牌由 `scene_portal.js` 和 `app.js` 在图片坐标内绘制，`scene/entrances.json` 保存成图上测量的横屏入口坐标。竖屏仍使用既有图和坐标；楼内文字由阅读卡片承载，八科正式图继续登记在 `beauty/builtin-art.json`，用户自己的同名美术仍优先。
