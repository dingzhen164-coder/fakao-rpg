# 🔮 法师成长记（法考 RPG）

把法考复习做成一个西方玄幻的成长游戏：你是王立法学魔法学院的学徒，导师是腹黑毒舌、讲法条一丝不苟的**艾琳学姐**（接 AI 现场说话）。
法考八科各是一种**天赋**：民法、刑法、民诉、刑诉、行政法、商经知、三国法、理论法。
每科的知识骨架是一本**咒文书**，咏唱（默写）、传授奥义（费曼讲解）、实战演练（案例小题）、温习符文（间隔复习卡片）、
真题试炼塔（单选 / 多选 / 不定项）、讨伐魔物（错题）一路练上去，**经验**推动**魔力（预估分）**，魔力决定**位阶**：

平民 50 → 魔法学徒 51–59（一至九星）→ **初级法师 60**（≈ 客观题 180 分及格线）→ 中级法师 65 → 高级法师 70 → 大魔导师 75 → 法圣 80 → 法神·上岸者 85

- 魔力是百分制：× 3 约等于客观题（满分 300）分数。它只是游戏里的进度刻度，不是真实的考试预测。
- 经验攒满一层不会自动升级：营地的经验条变金，出现「⚡ 按住晋升」，按住约 1.5 秒才晋升，弹出晋升大典。
- 跨大位阶（初级法师、中级法师……）要通过**晋升试炼**，并且最近两次**竞技场**（模考）都达线。
- 有效学习每分钟 +1 经验，前期升得快、后期慢；每天学满 180 分钟，到目标日（暂定 2027-09-10）正好 80 分。

这个程序是 [行测修仙传](https://github.com/dingzhen164-coder/xingce-rpg) 3.3.0 的完整复制改造版，两个程序可以装在同一台电脑、同一台平板上，互不影响
（设置目录 `~/.fakao-rpg`、默认端口 8766、平板 App 是另一个）。

- 只在自己电脑上运行（浏览器打开 `127.0.0.1:8766`，或者用 exe / Mac App 自己的窗口），数据放在 Obsidian 法考库的 `训练/` 文件夹，坚果云同步；
- 源码版只需要电脑上有 Python 3.8+，不用装别的；
- AI（判咏唱、传授奥义追问、出案例题、讲题、制卡、学姐说话）用你自己的 DeepSeek API key。

## 一、安装（只需在一台电脑上做一次）

1. 在 GitHub 仓库页面点 **Code → Download ZIP**，解压。
2. 在 Obsidian 法考库里新建文件夹 `训练/程序/`，把解压出来的**所有文件**复制进去。
   最后应该是：`法考/训练/程序/server.py`、`法考/训练/程序/rpg/`、`法考/训练/程序/web/` ……
   （放在库里，坚果云会同步到另一台电脑，两台都不用再装。）
3. 启动：
   - **Windows**：双击 `训练/程序/启动训练.bat`
   - **Mac**：双击 `训练/程序/启动训练.command`（第一次如果提示“无法打开”：右键 → 打开；
     或者在终端运行 `python3 "<库路径>/训练/程序/server.py"`）
4. 浏览器会自动打开训练页。第一次运行会在 `训练/` 里生成 `规则.md`、`角色设定.md`、`台词库·玄幻.md`、各科题库模板。
5. 点右上角 **设置**，填 DeepSeek 的 API key，点“测试 AI 连接”。
   **key 只保存在这台电脑**（`~/.fakao-rpg/settings.json`），另一台电脑要再填一次。

关掉黑色的终端窗口 = 关掉程序。

### 桌面版（exe，Windows）

不想开黑窗口、浏览器：到仓库的 **Releases** 下载 `fakao-mage.exe`，放进 `训练/程序/`，双击就在自己的窗口里打开
（关掉窗口 = 退出）。exe 里自带 Python、读 PDF 用的 pymupdf，不用装任何东西。
- 窗口用的是 Windows 自带的 Edge WebView2（Win10/11 一般都有）；万一窗口打不开，会自动改用浏览器。
- 启动信息、报错写在 `~/.fakao-rpg/启动日志.txt`。
- 第一次运行 Windows 可能提示“已保护你的电脑”：点“更多信息 → 仍要运行”（exe 没买签名证书）。

### Mac App（Apple 芯片：M 系列 / A 系列）

到 Releases 下载 `fakao-mage-mac.zip`，解压出「法师成长记」，拖进「应用程序」（**不要**放进坚果云同步的文件夹）。
- 第一次打开会提示“无法验证开发者”（没买苹果的开发者证书）：系统设置 → 隐私与安全性 → 往下找到「仍要打开」；
  或者在终端运行一次 `xattr -cr /Applications/法师成长记.app` 再双击。
- App 不在库里，会自己到坚果云同步文件夹、桌面、文稿里找法考库（有 `10-科目` 文件夹，或用过本程序的 `训练/`），找到就记住；找不到就到 设置 → 库路径 填一次。
- 本机设置（AI 的 key 等）每台电脑各存一份，Mac 上要再填一次。**两台电脑别同时开着法师成长记**（坚果云同步有延迟，存档会互相覆盖）。
- 更新：设置 → 🆕 版本与更新 → 检查更新 → 到 GitHub 下载新的 zip，替换「应用程序」里的旧版。

### 手机 / 平板（局域网模式）

电脑当主机，同一个 Wi-Fi 下的手机、平板用浏览器打开，数据只存电脑上这一份：
1. 电脑上 **设置 → 📱 手机 / 平板**，勾上“允许手机 / 平板连进来”，**重启程序**（源码版也可以 `python server.py --lan`）；
   Windows 防火墙弹窗点“允许”。
2. 手机扫设置页里的二维码，或者在浏览器输入那里显示的地址（`http://192.168.x.x:8766/`），输一次 6 位访问口令。
3. **安卓平板 / 手机：装「法师成长记」App**（Releases 里的 `fakao-mage.apk`，平板浏览器打开设置页也有下载按钮）。
   打开后它在 Wi-Fi 里自己找到电脑，全屏、没有浏览器的地址栏和工具栏；记住地址，下次直接进。
   返回键：先关弹窗 / 画面，再回营地，在营地按两次退出。源码在 `android/`，版本号跟 `rpg/version.py` 一起走。
   苹果：Safari「分享 → 添加到主屏幕」，从桌面图标打开就是全屏。电脑要开着、法师成长记要在运行。

口令和局域网开关只能在电脑上改；“换一个”口令后，连过的设备要重新输。

## 二、更新

**exe 版**：设置 → 🆕 版本与更新 → 检查更新 → 「更新并重启」，自动下载新 exe、换掉旧的、重新打开。
（发布方式：改 `rpg/version.py` 的版本号推到 main，GitHub Actions 会在 Windows 上打包 exe 发到 Releases，
见 `.github/workflows/build-exe.yml`；也可以在 Actions 页手动运行。）

**源码版**：重新 Download ZIP，把文件**覆盖**复制到 `训练/程序/`。你的数据在 `训练/` 下的其他文件夹里，不受影响。

程序升级如果改了配置文件的结构，会自动把你的 `规则.md` / `角色设定.md` / `台词库·玄幻.md` 备份成 `xxx.旧版.md`
再换成新版（网页顶部会提示）。你改过的内容可以从旧版里抄回来。

## 三、法考库怎么放、怎么开始

程序只**读**你库里的笔记，只**写** `训练/` 文件夹。建议的库结构（和之前法官成长记约定的一样）：

```
法考/
├─ 10-科目/
│   ├─ 民法/  …各章笔记.md
│   ├─ 刑法/  ├─ 民诉/  ├─ 刑诉/  ├─ 行政法/  ├─ 商经知/  ├─ 三国法/  └─ 理论法/
├─ 20-错题/  30-案例/  40-法条与年度变动/  50-复习管理/  60-真题库/  99-讲义PDF/  99-知识点库/
└─ 训练/            ← 程序的数据（规则、咒文书、题库、符文卡、手记、存档），第一次运行自动建
```

1. **资料**：`规则.md` 的「科目」一节默认每科读 `10-科目/<科目>` 文件夹里的全部笔记（`- 板块.民法: 10-科目/民法 | 民法`）。
   笔记太多超过读取上限时，改成指向更小的文件夹（如 `10-科目/民法/物权`）；也可以写成 `copilot/skills/` 下某个 skill 的名字。
   某科既没有资料也没有咒文书时显示「🔒 未解锁」，分批时自动跳过。
2. **咒文书**（`训练/骨架/<科目>.md`）：在「📕 咒文书」里让学姐按资料编一份草稿，对照教材核对、改好后「定稿」。
   格式：`## 大项`、`- 【术语】名称：解释`（必须说全的清单，法条序号、期限、数额写在这里）、`- 【思路】……`（要件、效果、易混点，说大意即可）。
3. **分批**：民法 + 刑法 → 民诉 + 刑诉 → 行政法 + 商经知 → 三国法 + 理论法，一批打通进下一批，全部打通 = 一轮征程。顺序在 `规则.md` 里改。
4. **每天**：营地看今日委托（学姐荐课）→「⚔ 冒险」里温习符文、练咒文书、闯真题试炼塔 → 网课时间在营地「听讲」里记一笔。
5. **模考 / 真考成绩**：「📖 编年史」里记，**按满分 300 填**，程序换算成百分制。最近两次模考较低的那次若高于当前魔力，经验直接补上。

### 题库（真题试炼塔）

每科一个文件 `训练/题库/<科目>真题.md`（第一次运行自动生成模板，模板里有示例）。一题的写法：

```markdown
## 题目 2023-卷二-51
### 知识点
表见代理
### 题型
多选
### 题干
（2023年法考卷二）……案情……
### 选项
A. ……
B. ……
C. ……
D. ……
### 答案
ABD
### 解析
依据《民法典》第172条……
```

- `### 题型` 写 **单选 / 多选 / 不定项**；不写时答案一个字母算单选、多个字母算多选。不定项哪怕答案只有一个字母，也按多选作答。
- 多选、不定项：点字母勾选、再点一次取消，选好点「下一题」；**全部选对才算对**（和法考一样，不给部分分）。
- 答案、解析不知道可以写「（待补）」，答案待补的题先不出。也可以在试炼塔里「📥 导入真题」批量入库。

### 和行测修仙传相比，这一版先收起的

- 粉笔模考的成绩单 / 拆卷分析（原「宗门大比」页）、时政「天机简报」、「成语实词录」：都是行测专用的，顶栏和咒文书页里不显示（代码还在）。

## 四、改规则 / 人设 / 台词（不用改代码）

在 Obsidian 里改这些文件，保存后**刷新网页**就生效：

| 文件 | 改什么 |
|---|---|
| `训练/规则.md` | 开始日期、目标日、每天分钟、位阶分数线、晋升试炼条件、天赋门槛、分批、科目资料、经验值……（规则名沿用行测底本的修仙说法，文件开头有对照表） |
| `训练/角色设定.md` | 你的 ID、头像（放进 `训练/`）；学姐怎么称呼你、导师名 / 头像 / 人设、吐槽尺度 |
| `训练/台词库·玄幻.md` | 学姐的备用台词（没连 AI 时用），随便加 |
| `训练/骨架/<科目>.md` | 咒文书（咏唱的标准） |
| `训练/题库/<科目>真题.md` | 真题 |

想加新功能、改界面：把这个仓库交给 AI，让它先读 `AGENTS.md`。

## 五、常见问题

- **修炼时间怎么算**：只有打开一项功课（咏唱咒文、传授奥义、实战演练、讨伐魔物、晋升试炼、温习符文……）并且在操作时才计时，做完看解析的 3 分钟也算；
  只是开着网页、看面板、和学姐闲聊不算。顶栏的计时器在计时时会亮起闪烁。线下做题的时间到“营地 → 野外历练 · 实战日志”手动补录。

- **打不开 / 闪退**：用终端运行 `python server.py`（Mac 用 `python3`）看报错。需要 Python 3.8 以上。
