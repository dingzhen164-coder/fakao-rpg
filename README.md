# 法官成长记

自用法考学习程序，把OCR考点资料、知识体系、间隔背诵、客观题和主观题表达连在一起。离线学习，DeepSeek按需调用。学习数据在你的Obsidian库，原教材和笔记只读。

## 下载与运行

在本仓库Releases下载Windows exe、M系列Mac zip或安卓APK。

- Windows：双击faguan-growth-windows.exe，保留控制台窗口，浏览器自动打开；关闭窗口退出。
- M系列Mac：解压后打开法官成长记.app。采用临时签名且未公证，首次打开可能需要在系统隐私与安全性设置中允许。它在后台运行；退出请在设置与更新点击退出电脑主机，避免两台电脑同时运行。
- 安卓：安装自用调试APK，输入电脑的局域网HTTP地址与端口（默认8766）。数据仍保存到电脑。
- iPad：Safari访问同一局域网地址，可添加至主屏幕。支持Apple Pencil；须保持电脑开启。
- 源码：Python3.8及以上，运行python server.py，无pip依赖。默认地址http://127.0.0.1:8766。用python server.py --no-browser启动但不自动打开网页。

## 第一次使用

1. 进入设置与更新，在电脑本机设置Obsidian库根目录。Windows可填C:\Users\29356\Desktop\法考obsidian\法考；Mac填自己的本机路径，路径不随坚果云同步。
2. 保存设置；进入资料整理，扫描资料目录或上传一个OCR Markdown。PDF暂不自动提取。
3. 对照OCR原文与教材原页，修改整理稿并勾选已核对。资料原文件始终只读，整理稿写到训练/资料整理/。
4. 进入知识体系，独立回忆考点并对照；手动制卡或在配置DeepSeek后按需生成卡片草稿，审阅后添加。
5. 客观题手动录入或从OCR随堂题草稿核对后添加，答案提交后才展示。多选和不定项按完整答案集合判对。
6. 主观题机考创建案例、问题和参考答案。每问的JSON可写为：

```json
[{"prompt":"问题内容","reference":"参考答案","points":[{"id":"p1","text":"可信采分点","score":2}]}]
```

没有可靠采分点时用points: []，作答后只对照答案，不生成AI分数。机考到时交卷，日常练习不强制截止；作答自动保存，交卷后开放参考答案。AI评分仅为练习参考，程序根据命中点算分。

## 局域网与离线

电脑设置勾选开启局域网、保存并退出重启。在系统网络设置查看电脑的局域网IPv4地址，用http://电脑IP:8766访问；电脑防火墙可能需要允许该程序在专用网络通信。平板口令在电脑设置页查看。电脑与平板须能互通，平板不独立保存整套学习数据。

背诵、体系自评、刷题判分、机考、笔记不需要互联网；AI、下载安装包需要联网。坚果云里显示云朵的资料先下载到本机。两台电脑请不要同时写存档，切换前退出程序并完成同步。

## AI和数据

设置中填写自己的DeepSeek模型与key。key只在本机~/.fakao-rpg/settings.json，不进仓库或同步盘。页面打开不调用AI，结果按资料版本缓存并记录接口token。长AI请求期间其他写操作可能等待。AI无法确定OCR法律内容时保留待核对信息。

存档在训练/存档/存档.json，原子写入，每日保存前备份，保留30天。手写笔迹和作答保存于存档；笔记文字另存Markdown。勿手动改稳定ID。

## 更新和首版限制

在设置与更新打开Releases，下载新版并替换程序；不要删除库里的训练目录。本版尚无程序内自动替换更新、PDF自动提取、图形导图编辑、整卷客观机考或正式电子法条检索；题库与主观题资料由用户提供，不预装教材。安卓调试签名缓存丢失可能需卸载重装，学习数据仍在电脑。正式签名与Mac公证需另行配置。
